Developed by: Ruben BL

This project was created as a prototype for an educational platform where students can learn various topics through a game-like process. The goal is to enhance student engagement by using interactive and playful methods that stimulate curiosity and interest.

The platform also explores the use of AI to dynamically generate educational games tailored to the learner’s interests, allowing for personalized course experiences.

This prototype was developed and presented at Universidad Tecnológica de Altamira as part of the Integration class.
